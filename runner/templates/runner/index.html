Módulo 01

La función
print()

print() es la función más fundamental de Python. Le indica al intérprete que tome lo que sea que esté dentro de los paréntesis y lo muestre en la consola. Toda tu interacción visible con el programa empieza aquí.

Qué hace print()
Toma uno o varios argumentos y los escribe en la salida estándar (stdout), seguidos de un salto de línea automático.
Strings (cadenas)
El texto debe ir entre comillas simples 'hola' o dobles "hola". Ambas son equivalentes en Python.
Números directos
Los números no necesitan comillas. print(42) imprime el entero 42 y print(3.14) imprime el float.
Múltiples argumentos
Puedes pasar varios valores separados por coma: print("Hola", nombre). Python los une con un espacio.

Cuando escribes print("¡Hola, mundo!"), las comillas le indican a Python que ese es un texto literal (string). El texto aparece sin comillas en la salida porque las comillas son solo la notación de Python, no parte del dato en sí.

Parámetros sep y end
Controla el separador entre valores y el carácter final
Python 3
▸ Salida del programa

sep controla qué carácter aparece entre los argumentos (por defecto un espacio). end controla qué carácter va al final de la línea (por defecto \n, que es un salto de línea). Modificarlos te da control total sobre el formato de salida.

F-strings — interpolación moderna
Incrusta variables y expresiones dentro de texto con f"..."
Python 3
▸ Salida del programa

Las f-strings se crean poniendo una f antes de la comilla inicial. Dentro de { } puedes escribir cualquier expresión Python válida: cálculos, variables, formateo de números como :.2f (2 decimales). Todo se evalúa en tiempo real.

Módulo 02

Variables:
guardar información

Una variable es como una caja etiquetada en la memoria del computador donde guardas un dato. En Python no necesitas declarar el tipo — el intérprete lo infiere automáticamente al asignar el valor.

str — Texto
Secuencias de caracteres entre comillas. "hola", 'mundo'. Soportan emojis, acentos y Unicode completo.
int — Entero
Números enteros sin límite de tamaño: 42, -7, 1_000_000. Los guiones bajos mejoran la legibilidad.
float — Decimal
Números con punto decimal: 3.14, -0.5, 1e10. Ideal para medidas, precios y cálculos continuos.
bool — Booleano
Solo dos valores: True o False. Controlan el flujo lógico del programa mediante condiciones.

Crear y usar variables
El operador = asigna valores — prueba cambiar los datos
Python 3
▸ Salida del programa

El signo = en Python es el operador de asignación. No significa "igual" como en matemáticas, sino "guarda este valor en esta caja". Se lee de derecha a izquierda: el valor de la derecha se almacena en la variable de la izquierda. La función type() revela qué tipo de dato contiene una variable.

Las variables pueden cambiar
Reasignación y operadores aumentados +=, -=, *=
Python 3
▸ Salida del programa

puntos = puntos + 25 significa: toma el valor actual de puntos, súmale 25 y guarda el resultado de nuevo en puntos. El operador += es un atajo equivalente. También existen -=, *=, /= y //= para las otras operaciones.

Módulo 03

Condicionales:
tomar decisiones

Los condicionales permiten que tu programa tome caminos distintos según si una condición es verdadera o falsa. Son el mecanismo con el que el código "piensa" y reacciona ante diferentes situaciones.

if — Si esto ocurre
Ejecuta un bloque de código solo si la condición es True. Si es False, el bloque se omite completamente.
↔
else — De lo contrario
Se ejecuta cuando la condición del if es False. Es el camino alternativo: o uno u otro, nunca ambos.
elif — Si no, si...
Permite encadenar varias condiciones. Se evalúan en orden; se ejecuta solo la primera que resulte verdadera.
Operadores de comparación
== igual · != distinto · > mayor · < menor · >= mayor o igual · <= menor o igual.

if simple y if / else
El camino más básico: ejecutar algo o no ejecutarlo

En Python, la indentación (4 espacios o 1 Tab) define qué código pertenece a cada bloque. Todo lo que va dentro del if debe estar indentado. Si quitas los espacios, Python lanzará un IndentationError. Prueba cambiar edad = 17 por edad = 20 y vuelve a ejecutar.

if / elif / else — múltiples ramas
Evalúa varias condiciones en cadena hasta encontrar la primera verdadera
Python 3
▸ Salida del programa

Python evalúa los elif de arriba hacia abajo y se detiene en el primero que sea True. Por eso el orden importa: si pusieras nota >= 60 primero, capturaría todos los casos y los elif siguientes nunca se ejecutarían. Prueba cambiar nota = 72 por otros valores como 85, 95 o 45.

Operadores lógicos: and, or, not
Combina varias condiciones en una sola expresión
Python 3
▸ Salida del programa

and requiere que ambas condiciones sean True. or requiere que al menos una sea True. not invierte el valor: si algo es True, lo convierte en False y viceversa. Puedes combinarlos con paréntesis para condiciones más complejas.

Condicional en una línea (ternario)
Sintaxis compacta para decisiones simples dentro de expresiones
Python 3
▸ Salida del programa

La sintaxis es: valor_si_true if condición else valor_si_false. Es útil para asignaciones simples en una sola línea. Sin embargo, para condiciones complejas es mejor el if/else normal: la legibilidad es más importante que la brevedad.

Módulo 04

Ciclos:
repetir acciones

Los ciclos permiten ejecutar un bloque de código múltiples veces sin tener que escribirlo repetidamente. Son la herramienta fundamental para procesar colecciones de datos y automatizar tareas repetitivas.

for — Para cada elemento
Itera sobre una secuencia (lista, rango, string). Ideal cuando sabes de antemano cuántas veces repetir.
while — Mientras se cumpla
Repite mientras una condición sea True. Ideal cuando no sabes cuántas iteraciones necesitarás.
break — Salir del ciclo
Detiene el ciclo inmediatamente, sin importar si quedan más iteraciones. Sale del bucle actual por completo.
continue — Saltar iteración
Salta al inicio de la siguiente iteración, ignorando el resto del código en la iteración actual.

Ciclo for con range()
Repite un bloque un número fijo de veces usando un rango numérico
Python 3
▸ Salida del programa

range(inicio, fin) genera números desde inicio hasta fin - 1 (el fin no se incluye). range(0, 11, 2) agrega un tercer argumento: el paso, que indica de cuánto en cuánto avanzar. La variable i (o cualquier nombre que elijas) toma cada valor en cada vuelta.

for sobre listas y strings
Itera directamente sobre colecciones de datos sin necesitar índices
Python 3
▸ Salida del programa

En Python, un for puede iterar sobre cualquier objeto iterable: listas [], strings, tuplas (), y más. La variable fruta toma el valor de cada elemento en cada vuelta. No necesitas índices ni range(len(lista)) a menos que necesites el número de posición.

Ciclo while
Repite mientras la condición sea verdadera — ideal para menús y validaciones
Python 3
▸ Salida del programa

En un while, siempre debes asegurarte de que la condición eventualmente se vuelva False, o tendrás un bucle infinito. En el primer ejemplo, contador -= 1 lo hace decrecer hasta llegar a 0. El servidor tiene un timeout de 5 segundos que detiene bucles infinitos automáticamente.

break y continue
Controla el flujo dentro del ciclo: salir o saltar una iteración
Python 3
▸ Salida del programa

break abandona el ciclo completamente al momento de ejecutarse. continue ignora el resto del cuerpo del ciclo y salta directo a la siguiente iteración. El operador % (módulo) devuelve el residuo de una división: i % 3 == 0 es True cuando i es divisible por 3.

Ciclos + Condicionales juntos
Combina todo lo aprendido para resolver problemas reales
